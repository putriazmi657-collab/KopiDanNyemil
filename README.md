
# ☕ Kopi dan Nyemil

## Deskripsi Aplikasi
Kopi dan Nyemil merupakan aplikasi pemesanan kopi dan camilan berbasis Android. Aplikasi ini dibuat untuk memudahkan pengguna dalam memilih menu, melakukan pemesanan, dan mengisi alamat pengiriman.

## Fitur Aplikasi
1. **Splash Screen** – Tampilan pembuka aplikasi.
2. **Sign Up** – Pilihan untuk membuat akun atau login.
3. **Register** – Membuat akun baru.
4. **Login** – Masuk menggunakan username dan password.
5. **Home** – Menampilkan daftar menu kopi dan camilan.
6. **Profile** – Menampilkan informasi profil pengguna.
7. **Alamat Pengiriman** – Mengisi nama penerima, nomor telepon, dan alamat.
8. **Konfirmasi Pesanan** – Menampilkan detail pesanan dan total pembayaran.

## Teknologi yang Digunakan
- Android Studio
- Kotlin
- XML Layout
- Gradle
- Git dan GitHub

## Cara Menjalankan Aplikasi
1. Clone repository ini:
   ```bash
   git clone https://github.com/putriazmi657-collab/KopiDanNyemil.git
   ```
2. Buka Android Studio.
3. Pilih Open dan cari folder KopiDanNyemil.
4. Tunggu proses Gradle Sync selesai.
5. Hubungkan perangkat Android atau gunakan emulator.
6. Klik tombol Run untuk menjalankan aplikasi.

## Penyimpanan Data
Aplikasi menggunakan data lokal sederhana (SharedPreferences) untuk menyimpan informasi akun dan alamat pengguna. Aplikasi ini tidak menggunakan database server.
